# AI Resume Screening & Job Matching System

An AI-powered resume screening and job matching system built with Python, Natural Language Processing (NLP), and Streamlit.

## 📌 Project Overview

This project analyzes candidate resumes and compares them with job requirements to calculate a candidate match score.

The system helps identify:
- Candidate match percentage
- Matched skills
- Missing skills
- Education score
- Experience score
- NLP-based score
- Recommended job role
- Overall match level

## 🚀 Features

- 📄 Resume analysis
- 🤖 AI-based candidate screening
- 🧠 NLP-based resume and job matching
- 🛠️ Skills matching
- 📊 Candidate score comparison
- 📈 Score breakdown
- 💼 Automatic job recommendation
- 🔍 Candidate search and filtering
- 📥 CSV results export
- 📊 Excel report export
- 🌐 Streamlit-based application

## 🛠️ Technologies Used

- Python
- Pandas
- Natural Language Processing (NLP)
- TF-IDF
- Cosine Similarity
- Machine Learning
- Streamlit
- OpenPyXL

## ⚙️ How It Works

1. Resume information is extracted and processed.
2. Resume content is compared with job requirements.
3. NLP techniques are used to calculate similarity.
4. Skills, education, and experience are analyzed.
5. A final candidate score is calculated.
6. Candidates are classified based on their match level.
7. The system recommends the most suitable job role.
8. Results can be downloaded as CSV or Excel reports.

## 📊 Results

The application provides a dashboard containing:

- Candidate match scores

- Skill scores

- Experience scores

- Recommended job roles
